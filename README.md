# Warranty Manager – Ηλεκτρονική ενεργοποίηση εγγυήσεων (WordPress plugin)

Plugin για WordPress που επιτρέπει στους πελάτες να ενεργοποιούν μόνοι τους την εγγύηση του προϊόντος τους με τον σειριακό αριθμό. Στέλνει αυτόματα τον κωδικό εγγύησης και υπενθυμίσεις λήξης με email/SMS, και δίνει στην εταιρεία διαχειριστικό περιβάλλον μέσα στο wp-admin.

Ο κώδικας του plugin βρίσκεται στον φάκελο [`warranty-manager/`](warranty-manager/).

Η πρόσβαση στο διαχειριστικό απαιτεί επαλήθευση δύο βημάτων, μπορεί να περιοριστεί σε συγκεκριμένους χρήστες και IP, και τα στοιχεία πελατών αποθηκεύονται κρυπτογραφημένα στη βάση. Δείτε την ενότητα [Ασφάλεια διαχειριστικού](#ασφάλεια-διαχειριστικού).

## Τι κάνει

**Για τον πελάτη (σελίδες του site)**
1. Πληκτρολογεί τον σειριακό αριθμό. Το σύστημα ελέγχει ότι υπάρχει και δεν έχει χρησιμοποιηθεί.
2. Συμπληρώνει ονοματεπώνυμο, email και κινητό, διαβάζει και αποδέχεται τους όρους εγγύησης.
3. Βλέπει επισκόπηση των στοιχείων του και μπορεί να τα διορθώσει πριν την οριστική υποβολή.
4. Παίρνει μοναδικό κωδικό εγγύησης (π.χ. `WR-7K3M-Q9XP`) στην οθόνη, με email και με SMS.
5. Μπορεί αργότερα να δει την κατάσταση και τη λήξη της εγγύησης στη σελίδα «Έλεγχος εγγύησης», με κωδικό εγγύησης και σειριακό. Δεν χρειάζεται λογαριασμός ή κωδικός πρόσβασης.

**Για την εταιρεία (wp-admin → Εγγυήσεις)**
- **Επισκόπηση:** ενεργές, ληγμένες και όσες λήγουν σε 30 ημέρες, ενεργοποιήσεις ανά μήνα και ανά προϊόν.
- **Εγγυήσεις:**
  - αναζήτηση με κωδικό, σειριακό, email, τηλέφωνο ή όνομα, και φίλτρα
  - εξαγωγή σε Excel (CSV)
  - διόρθωση στοιχείων, αλλαγή λήξης, ακύρωση/επαναφορά
  - επαναποστολή επιβεβαίωσης, ανωνυμοποίηση
  - χειροκίνητη ενεργοποίηση για τηλεφωνικές παραγγελίες ή αγορές από το κατάστημα
- **Σειριακοί αριθμοί:** αναζήτηση, προσθήκη ενός σειριακού, ακύρωση (π.χ. για κλεμμένο προϊόν).
- **Εισαγωγή από Excel:**
  - Δέχεται `.xlsx` και `.csv` (και CSV από ελληνικό Excel, σε κωδικοποίηση Windows-1253).
  - Αναγνωρίζει αυτόματα τις στήλες.
  - Επεξεργάζεται το αρχείο σε τμήματα με μπάρα προόδου, ώστε μεγάλα αρχεία να μην κόβονται σε shared hosting.
  - Δίνει αναφορά διπλότυπων και λαθών.
  - Κάθε εισαγωγή μπορεί να αναιρεθεί.
- **Προϊόντα:** διάρκεια εγγύησης ανά μοντέλο.
- **Όροι εγγύησης:** κάθε αλλαγή δημοσιεύεται ως νέα έκδοση και οι παλιές δεν τροποποιούνται.
- **Ειδοποιήσεις:**
  - Κανόνες του τύπου «Χ ημέρες πριν τη λήξη», με email/SMS προς τον πελάτη ή συγκεντρωτικό email προς την εταιρεία.
  - Ιστορικό αποστολών.
- **Ρυθμίσεις:** κείμενα μηνυμάτων, πάροχος SMS, CAPTCHA, GDPR, δοκιμαστική αποστολή.
- **Ιστορικό ενεργειών:** κάθε προβολή, αλλαγή και εξαγωγή στοιχείων πελατών από χρήστες του admin.

## Εγκατάσταση

Απαιτήσεις: WordPress 6.2+ και PHP 8.1+ με τις επεκτάσεις `zip` και `xmlreader`, που υπάρχουν σχεδόν πάντα στο cPanel. Δεν χρειάζεται WooCommerce ούτε Composer.

1. **Κλειδί κρυπτογράφησης (υποχρεωτικό).** Προσθέστε στο `wp-config.php` (cPanel → File Manager), πάνω από τη γραμμή «That's all, stop editing!»:
   ```php
   define( 'WR_ENCRYPTION_KEY', '...' );
   ```
   Ένα νέο κλειδί εμφανίζεται έτοιμο για αντιγραφή την πρώτη φορά που θα ανοίξετε το μενού «Εγγυήσεις». Μπορείτε επίσης να το δημιουργήσετε με `php -r 'echo base64_encode(random_bytes(32));'`. **Κρατήστε αντίγραφο του κλειδιού σε ασφαλές μέρος, χωριστά από τα backup της βάσης, και μην το αλλάξετε ποτέ.** Χωρίς αυτό τα στοιχεία πελατών δεν ανακτώνται. Μέχρι να οριστεί, η φόρμα του site δεν δέχεται καταχωρήσεις.
2. Συμπιέστε τον φάκελο `warranty-manager` σε `warranty-manager.zip` και ανεβάστε τον από **Πρόσθετα → Προσθήκη νέου → Μεταφόρτωση**. Εναλλακτικά, ανεβάστε τον φάκελο στο `wp-content/plugins/`. Μετά ενεργοποιήστε το plugin.
3. Δημιουργήστε δύο σελίδες:
   - «Ενεργοποίηση εγγύησης» με περιεχόμενο `[warranty_activate]`
   - «Έλεγχος εγγύησης» με περιεχόμενο `[warranty_check]`
4. Στο **Εγγυήσεις → Ρυθμίσεις** συμπληρώστε:
   - το URL της σελίδας «Έλεγχος εγγύησης»
   - το email της εταιρείας
   - τα κλειδιά Cloudflare Turnstile (δωρεάν CAPTCHA)
   - τον πάροχο SMS
5. Στο **Εγγυήσεις → Όροι εγγύησης** επικολλήστε τους όρους σας και δημοσιεύστε.
6. Στο **Εγγυήσεις → Εισαγωγή από Excel** ανεβάστε τους σειριακούς.

### Cron στο cPanel (απαραίτητο για τις υπενθυμίσεις)

Το WordPress από μόνο του τρέχει προγραμματισμένες εργασίες μόνο όταν το site έχει επισκέψεις. Για αξιόπιστες ειδοποιήσεις:

1. Στο `wp-config.php` προσθέστε:
   ```php
   define( 'DISABLE_WP_CRON', true );
   ```
2. Στο cPanel → **Cron Jobs** προσθέστε εργασία κάθε 15 λεπτά:
   ```
   */15 * * * * wget -q -O - "https://www.example.gr/wp-cron.php?doing_wp_cron" >/dev/null 2>&1
   ```
   ή, αν προτιμάτε PHP CLI:
   ```
   */15 * * * * cd /home/USERNAME/public_html && /usr/local/bin/php wp-cron.php >/dev/null 2>&1
   ```

Στη σελίδα **Ειδοποιήσεις** φαίνεται πότε έτρεξε τελευταία φορά ο έλεγχος. Αν δεν έχει τρέξει για πάνω από 3 ώρες, εμφανίζεται προειδοποίηση.

### Email

Μη στέλνετε μέσω του mail server του cPanel, γιατί τα μηνύματα καταλήγουν συχνά στα spam.

1. Εγκαταστήστε ένα SMTP plugin (π.χ. **FluentSMTP** ή **WP Mail SMTP**) και συνδέστε το με Brevo, Amazon SES, Postmark ή τον mail server σας.
2. Ρυθμίστε τις εγγραφές SPF/DKIM/DMARC στο domain από το cPanel → Zone Editor.

Το plugin στέλνει μέσω του `wp_mail()`, οπότε χρησιμοποιεί αυτόματα το SMTP plugin.

### SMS

Η σύνδεση είναι γενική μέσω HTTP και ταιριάζει στους περισσότερους παρόχους (Yuboto, Apifon, Routee, Twilio κ.ά.).

Ρυθμίζονται τα εξής:
- URL του API
- μέθοδος
- headers
- σώμα αιτήματος, με τα πεδία `{to}`, `{message}`, `{sender}` και `{api_key}`

Για να μη μένει το API key στη βάση, ορίστε το στο `wp-config.php` και γράψτε `{api_key}` στα headers/σώμα:

```php
define( 'WR_SMS_API_KEY', 'το-κλειδί-σας' );
```

Παράδειγμα (JSON API με Bearer token):

```
URL:      https://api.provider.example/sms/send
Headers:  Content-Type: application/json
          Authorization: Bearer {api_key}
Σώμα:     {"to":"{to}","from":"{sender}","text":"{message}"}
```

Δοκιμάστε την αποστολή από τις Ρυθμίσεις → «Δοκιμαστική αποστολή».

### Caching

Αν χρησιμοποιείτε plugin cache (LiteSpeed Cache, WP Rocket κ.λπ.), εξαιρέστε από το cache τις δύο σελίδες με τα shortcodes. Το plugin στέλνει ήδη headers `no-cache` στις υποβολές, αλλά η ρητή εξαίρεση είναι ασφαλέστερη.

## Ασφάλεια διαχειριστικού

Η σελίδα **Εγγυήσεις → Ασφάλεια & πρόσβαση** δείχνει την τρέχουσα κατάσταση, τους χρήστες με πρόσβαση και τα πρόσφατα συμβάντα ασφαλείας.

### Κρυπτογράφηση στη βάση
- **Τι κρυπτογραφείται:** ονοματεπώνυμο, email, κινητό, σημειώσεις, καθώς και η IP και η συσκευή της αποδοχής όρων και οι παραλήπτες μηνυμάτων. Χρησιμοποιείται libsodium (XSalsa20-Poly1305).
- **Τι προστατεύει:** όποιος αποκτήσει αντίγραφο της βάσης (backup, SQL injection από άλλο plugin, πρόσβαση στο phpMyAdmin) δεν μπορεί να διαβάσει τα στοιχεία πελατών χωρίς το κλειδί του `wp-config.php`.
- **Πώς γίνεται η αναζήτηση:** με κρυπτογραφικά ευρετήρια (HMAC). Το email και το κινητό αναζητούνται ολόκληρα, και το όνομα με ολόκληρες λέξεις (π.χ. το επώνυμο). Δεν γίνεται αναζήτηση με κομμάτι λέξης.
- **Υπάρχοντα δεδομένα:** όσα καταχωρήθηκαν πριν οριστεί το κλειδί κρυπτογραφούνται αυτόματα μόλις οριστεί.

### Υποχρεωτική επαλήθευση δύο βημάτων (2FA)
- **Ρύθμιση:** κάθε χρήστης, την πρώτη φορά που ανοίγει το μενού «Εγγυήσεις», σκανάρει έναν κωδικό QR με εφαρμογή επαλήθευσης (Google Authenticator, Microsoft Authenticator κ.ά.). Παίρνει και 10 κωδικούς ανάκτησης μιας χρήσης.
- **Διάρκεια επαλήθευσης:** ισχύει μόνο για τη συγκεκριμένη σύνδεση, IP και browser, για 8 ώρες. Λήγει νωρίτερα μετά από 30 λεπτά αδράνειας ή με την αποσύνδεση. Ένα κλεμμένο cookie σε άλλον υπολογιστή δεν αρκεί.
- **Λάθος κωδικοί:** μετά από 5 λάθος κωδικούς ο χρήστης κλειδώνεται για 15 λεπτά και ειδοποιείται το email της εταιρείας.
- **Εξαγωγή σε Excel:** ζητά ξανά κωδικό 2FA, καταγράφεται και ειδοποιεί με email την εταιρεία.
- **Χαμένο κινητό:** αν κάποιος χάσει κινητό και κωδικούς ανάκτησης, ένας άλλος διαχειριστής πατά «Επαναφορά 2FA». Αν είναι ο μοναδικός διαχειριστής, προσθέτει προσωρινά `define( 'WR_LOGIN_2FA', false );` στο wp-config.php μέσω cPanel, μπαίνει, πατά «Επαναφορά 2FA» στον εαυτό του και σβήνει ξανά τη γραμμή.

### 2FA στη σύνδεση του WordPress (χωρίς Wordfence)
Το plugin προστατεύει και την ίδια τη σελίδα σύνδεσης `wp-login.php`, χωρίς άλλο plugin:

- **Ποιοι χρειάζονται 2FA:** οι ρόλοι διαχειριστής, editor, shop manager και «Εξυπηρέτηση εγγυήσεων», καθώς και όποιος έχει πρόσβαση στις εγγυήσεις. Μετά τον κωδικό πρόσβασης ζητείται ο 6ψήφιος κωδικός από το κινητό, ή ένας κωδικός ανάκτησης. Χωρίς αυτόν δεν δημιουργείται καν σύνδεση.
- **Ένας κωδικός για όλα:** η ίδια καταχώριση στην εφαρμογή επαλήθευσης ισχύει και για το σύστημα εγγυήσεων. Μετά τη σύνδεση με 2FA δεν ζητείται δεύτερος κωδικός για τις εγγυήσεις.
- **Πρώτη σύνδεση χωρίς 2FA:** όποιος από αυτούς τους ρόλους δεν έχει ρυθμίσει ακόμα 2FA μεταφέρεται αμέσως στη ρύθμιση. Δεν μπορεί να κάνει τίποτα άλλο στο wp-admin μέχρι να την ολοκληρώσει.
- **Ειδοποίηση:** με την ενεργοποίηση 2FA στέλνεται email στον χρήστη και στην εταιρεία. Αν κάποιος με κλεμμένο κωδικό πρόσβασης προλάβει να ρυθμίσει δικό του κινητό, θα το μάθετε αμέσως. **Γι' αυτό ρυθμίστε 2FA σε όλους τους διαχειριστές αμέσως μετά την εγκατάσταση.**
- **Βήμα κωδικού δεμένο με τη συσκευή:** η σελίδα του κωδικού ισχύει 5 λεπτά και μόνο από τον ίδιο browser και την ίδια IP.
- **Κλειστές «πίσω πόρτες»:** για αυτούς τους χρήστες η σύνδεση μέσω XML-RPC και application passwords είναι κλειστή, ώστε να μην παρακάμπτεται το 2FA.
- **Όριο αποτυχημένων συνδέσεων:** 10 αποτυχίες από την ίδια IP σε 15 λεπτά οδηγούν σε αποκλεισμό 30 λεπτών, ακόμη και με σωστό κωδικό. Ο αποκλεισμός καταγράφεται.
- **Γενικό μήνυμα λάθους:** η σελίδα σύνδεσης δεν αποκαλύπτει πια αν ένα όνομα χρήστη υπάρχει.
- **Επιλογή ρόλων:** αλλάζουν με `define( 'WR_2FA_ROLES', 'administrator,editor' );`. Συνδρομητές και πελάτες δεν επηρεάζονται.

### Περιορισμός σε συγκεκριμένους χρήστες και IP
Ορίζονται **μόνο** στο `wp-config.php`. Έτσι, ακόμη κι αν παραβιαστεί ένας λογαριασμός διαχειριστή, δεν μπορεί να αλλάξει τους περιορισμούς από το wp-admin:

```php
define( 'WR_ALLOWED_USERS', 'maria,giorgos' );               // μόνο αυτοί οι χρήστες
define( 'WR_ALLOWED_IPS', '203.0.113.10, 198.51.100.0/24' ); // μόνο από αυτές τις IP / δίκτυα
define( 'WR_IDLE_MINUTES', 30 );                             // προαιρετικό
define( 'WR_2FA_SESSION_HOURS', 8 );                         // προαιρετικό
define( 'DISALLOW_FILE_EDIT', true );                        // συνιστάται
```

- Όσοι χρήστες ή IP βρίσκονται εκτός λίστας δεν βλέπουν καν το μενού. Κάθε προσπάθεια πρόσβασης καταγράφεται.
- Το `WR_ALLOWED_IPS` έχει νόημα μόνο αν το γραφείο σας έχει **σταθερή IP** ή χρησιμοποιείτε VPN. Αν κλειδωθείτε έξω, σβήστε τη γραμμή από το wp-config.php μέσω cPanel.
- Αν το site είναι πίσω από Cloudflare, ενεργοποιήστε στις Ρυθμίσεις την επιλογή «CF-Connecting-IP», ώστε να αναγνωρίζεται η πραγματική IP.

### Επιπλέον μέτρα που συστήνονται για όλο το WordPress
- HTTPS παντού (AutoSSL του cPanel).
- Δυνατοί, μοναδικοί κωδικοί πρόσβασης για όλους τους χρήστες. Το 2FA και το όριο προσπαθειών σύνδεσης τα καλύπτει ήδη το plugin.
- Όσο λιγότερα plugins και χρήστες διαχειριστή γίνεται, και τακτικές ενημερώσεις.
- Αν το επιτρέπει η φιλοξενία, περιορισμός του `/wp-admin` και του `wp-login.php` σε IP γραφείου μέσω `.htaccess` ή του «IP Blocker»/«Directory Privacy» του cPanel.

| Δικαίωμα | Τι επιτρέπει | Ποιος το έχει |

| `wr_edit` | Διόρθωση στοιχείων πελάτη, χειροκίνητη ενεργοποίηση, επαναποστολή | Διαχειριστής, «Εξυπηρέτηση εγγυήσεων» |

Για υπαλλήλους εξυπηρέτησης δημιουργήστε χρήστη με ρόλο **«Εξυπηρέτηση εγγυήσεων»**. Αν θέλετε πρόσβαση μόνο από συγκεκριμένους διαχειριστές, ορίστε το `WR_ALLOWED_USERS`. Τότε κανείς άλλος δεν μπαίνει, όποιον ρόλο κι αν έχει.

## GDPR

- **Ελαχιστοποίηση δεδομένων:** ζητούνται μόνο ονοματεπώνυμο, email και κινητό.
- **Απόδειξη αποδοχής όρων:** για κάθε ενεργοποίηση αποθηκεύονται η έκδοση των όρων και το SHA-256 του κειμένου, η ημερομηνία/ώρα, η IP και η συσκευή. Οι εκδόσεις των όρων δεν τροποποιούνται ποτέ. Αν οι όροι αλλάξουν ενώ ο πελάτης συμπληρώνει τη φόρμα, του ζητείται να αποδεχθεί τη νέα έκδοση.
- **Δικαιώματα υποκειμένων:** το plugin συνδέεται με τα εργαλεία του WordPress (**Εργαλεία → Εξαγωγή / Διαγραφή προσωπικών δεδομένων**) με βάση το email. Υπάρχει επίσης κουμπί ανωνυμοποίησης σε κάθε εγγύηση.
- **Διατήρηση:** τα στοιχεία πελατών ανωνυμοποιούνται αυτόματα Ν έτη μετά τη λήξη (προεπιλογή 6, ρυθμίζεται). Ο σειριακός και οι ημερομηνίες μένουν για στατιστικά.
- **Ιστορικό πρόσβασης:** καταγράφεται κάθε προβολή, αλλαγή και εξαγωγή στοιχείων πελατών από το admin. Το ιστορικό κρατά μόνο ποια πεδία άλλαξαν, όχι τις τιμές, ώστε να μη γίνει δεύτερο αντίγραφο προσωπικών δεδομένων.
- **Κρυπτογράφηση και πρόσβαση:** δείτε την ενότητα «Ασφάλεια διαχειριστικού» παραπάνω. Στις λίστες του admin τα email και τα τηλέφωνα εμφανίζονται μερικώς κρυμμένα. Ολόκληρα φαίνονται μόνο στην καρτέλα της εγγύησης, και κάθε προβολή καταγράφεται.
- **Πολιτική απορρήτου:** το plugin προτείνει κείμενο στις **Ρυθμίσεις → Απόρρητο → Οδηγός πολιτικής**.
- **Ασφάλεια φόρμας:**
  - όριο προσπαθειών ανά IP και Cloudflare Turnstile
  - honeypot κατά των bots
  - γενικό μήνυμα λάθους, ώστε να μη φαίνεται αν ένας σειριακός υπάρχει
  - υπογεγραμμένα (HMAC) δεδομένα μεταξύ των βημάτων της φόρμας
  - ατομική (atomic) δέσμευση του σειριακού, ώστε να μην ενεργοποιηθεί δύο φορές

Τα νομικά κείμενα (όροι εγγύησης, πολιτική απορρήτου, διάρκεια διατήρησης) χρειάζεται να τα εγκρίνει ο νομικός σας ή ο DPO. Χρειάζονται επίσης συμβάσεις επεξεργασίας (DPA) με τους παρόχους email, SMS και hosting.

## Αρχείο εισαγωγής

Πρώτο φύλλο του Excel. Η γραμμή επικεφαλίδων είναι προαιρετική.

| Σειριακός | Μοντέλο | Ημερομηνία πώλησης |
|---|---|---|
| AB-000001 | HX-200 | 15/03/2026 |
| AB-000002 | HX-300 | |

- **Επικεφαλίδες που αναγνωρίζονται:**
  - Serial / SN / Σειριακός
  - Model / Μοντέλο / Κωδικός / SKU
  - Date / Ημερομηνία
- **Χωρίς επικεφαλίδες:** A = σειριακός, B = μοντέλο, C = ημερομηνία.
- **Ημερομηνίες:** δέχεται ημερομηνίες του Excel, `ηη/μμ/εεεε` και `εεεε-μμ-ηη`.
- **Ταίριασμα σειριακών:** γίνεται χωρίς διάκριση πεζών/κεφαλαίων, κενών και παυλών, ώστε το `ab 000001` να ταιριάζει με το `AB-000001`. Ελληνικά γράμματα που μοιάζουν με λατινικά (Α, Β, Ε, Κ…) αντιστοιχίζονται στα λατινικά, για πελάτες που πληκτρολογούν με ελληνικό πληκτρολόγιο.
- **Έναρξη εγγύησης:** μετράει από την ενεργοποίηση ή από την ημερομηνία πώλησης του αρχείου (ρύθμιση).
